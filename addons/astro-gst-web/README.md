# Astro GST Web

## Description

This project is a web interface built with Astro and React for interacting with and managing Selkies GStreamer pipelines. It provides a user-friendly way to control and monitor GStreamer pipelines within a web browser.

## Features

*   **Astro Framework:** Built using the Astro static site generator for performance and flexibility.
*   **React Components:** Utilizes React components for interactive UI elements.
*   **Tailwind CSS:** Styled with Tailwind CSS for a modern and responsive design.
*   **ShadcnUI:** Implements accessible UI components from ShadcnUI.

## Getting Started

1.  **Prerequisites:**

    *   Node.js (>=20.9.0)
    *   pnpm (>=10.4.0)
2.  **Installation:**

    ```bash
    pnpm install
    ```
3.  **Development:**

    ```bash
    pnpm run dev
    ```

    This command starts the Astro development server.
4.  **Building:**

    ```bash
    pnpm run build
    ```

    This command builds the project for production.
5.  **Previewing:**

    ```bash
    pnpm run preview
    ```

    This command serves it locally for previewing.
